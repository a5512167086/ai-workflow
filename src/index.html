          工作流程模式
          
              
          自動：驗證與審查通過後自動 commit。手動：不自動 commit，每個任務完成後等待你測試。與 Windows／WSL 執行環境無關。
          
              
          
                模式
                
          
                  
                  
                
          
              
          
            
          
            
          
              
          全域同時執行上限
          
              
          適用所有專案；其他專案會排隊，等待人工驗收的專案不占名額。
          
              
          
                
                
                
              
          
            
          
          
          
        
          
        
          
          
          AI 角色與模型
          
          
          每個階段可獨立選擇 AI、模型與推理強度；空白＝CLI 預設。PRD 審查與程式碼審查可以選「雙人審查」：Claude 與 Codex 各審一次，兩份意見分開顯示，兩份都通過才算通過。只有一個 AI 可用或額度用完改用另一個 AI 時，套用那個 AI 的設定。
          
          
          Pro 訂閱不含 Fable：在 Claude Code 看得到模型選項，也可能需要額外 usage credits。此處建議清單不列 Fable。Handover 是給下一個 AI session 的交接紀錄，會記錄已完成內容、驗證結果與待處理事項。
          
          
          
          
          
          
          
        
          
        
          
          
          CLI 執行環境
          
          
          預設依專案位置自動選擇：專案在 Windows 磁碟就用 Windows 的 CLI，在 WSL（\wsl.localhost…）就用該發行版裡的 CLI，也可以手動指定。只有一個 AI 可用時，以獨立對話完成實作與審查。
