加入專案

專案資料夾裡不會新增任何檔案；流程資料放在 ~/.ai-workflow/projects/

工作流程模式

自動：驗證與審查通過後自動 commit。手動：不自動 commit，每個任務完成後等待你測試。適用所有專案，與 Windows／WSL 執行環境無關。

模式

全域同時執行上限

適用所有專案；其他專案會排隊，等待人工驗收的專案不占名額。

AI 角色與模型

九個階段各自選擇 AI、模型與推理強度；空白＝CLI 預設。PRD 審查與程式碼審查可以選「雙人審查」：Claude 與 Codex 各審一次，兩份都通過才算通過。只有一個 AI 可用或額度用完改用另一個 AI 時，套用那個 AI 的設定。

    模型清單直接向 Claude Code 與 Codex CLI 查詢，就是這個帳號可用的模型；Pro 訂閱使用 Fable 可能需要額外 usage credits。Handover 是給下一個 AI session 的交接紀錄。

    節省 Token

    縮小每次送給 AI 的內容。AI 在一個 session 裡每發一次請求都會重讀整份 prompt，所以 prompt 少一點，整個 session 就少很多。適用所有專案；各專案的「用量」分頁會顯示估計省下多少。

    精簡回覆

    要求 AI 結論先行、不寒暄、不重述，程式碼、路徑與錯誤訊息保留原文。只套用在下列角色的回覆；PRD、任務清單、handover 與需求釐清不套用。

    流程參數

    適用所有專案。任務數 0＝交給 AI 決定；自動模式的分支名稱是「前綴＋功能」。

    CLI 執行環境

    預設依專案位置自動選擇：專案在 Windows 磁碟就用 Windows 的 CLI，在 WSL（\wsl.localhost…）就用該發行版裡的 CLI，也可以手動指定。只有一個 AI 可用時，以獨立對話完成實作與審查。
